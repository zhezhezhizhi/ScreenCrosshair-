# ScreenCrosshair (屏幕准星)

ScreenCrosshair 是一个专为 FPS 游戏（三角洲行动、CS2、CF、无畏契约、Apex、PUBG 等）打造的 Windows 桌面准星工具。

写这个工具的初衷是因为很多现有准星软件在游戏开启 4:3 拉伸分辨率（如 1920×1440）或系统开了 125%/150% 缩放时容易出现准星偏离中心的问题，而且传统十字准星的横线和竖线往往是上下堆叠绘制的，中间接缝很影响视线。本项目基于 WPF/Win32 底层硬件加速渲染，做了严格的物理像素对齐与拉伸适配，单文件绿色免安装，不注入或读写游戏内存。

## 下载与运行

普通玩家直接下载编译好的单文件即可，无需配置任何开发环境：

👉 **[前往 Releases 页面下载 ScreenCrosshair.exe](https://github.com/zhezhezhizhi/ScreenCrosshair-/releases)**

- **单文件免安装**：解压即用，不写注册表。
- **占用极低**：内存占用约 15MB 左右，纯顶层无焦点透明窗口，不掉帧、不抢游戏焦点。
- **安全防封**：仅作为桌面最顶层透明覆盖层，完全不接触游戏内存或进程句柄。

## 快捷键说明

| 按键 | 说明 |
| :--- | :--- |
| **F8** | 游戏内一键开启 / 隐藏准星 |
| **F10** | 随时呼出 / 隐藏控制面板 |
| **方向键 (↑ ↓ ← →)** | 在控制面板中微调准星位置（支持 0.1 / 1 像素微调） |
| **ESC** | 在屏幕拖拽校准模式下快速退出并锁定坐标 |

*(以上快捷键均可在「主题·按键·个性化」页面中自定义修改或录制)*

## 主要功能

- **一体化平面十字几何**：  
  横竖线采用布尔几何联合渲染，处于同一个物理平面。中心交汇处没有交叉黑线，Gap（中心间隙）为 0 或负数时也不会出现缝隙或描边重叠。
- **拉伸分辨率与 DPI 居中自适应**：  
  自动适配 1080P、2K、4K 以及游戏内 4:3 拉伸分辨率（如 1920×1440）。点击面板上的【检查/刷新分辨率】或【一键居中归零】即可强制对齐真实屏幕中心。
- **直接在屏幕上拖拽校准**：  
  支持直接在游戏画面上按住鼠标左键拖动准星对准枪口靶心，按 ESC 即可完成定位并恢复鼠标穿透。
- **自定义图片准星**：  
  支持导入 PNG / JPG / GIF 等格式的图片准星，支持锁定图片长宽比，也可自由横向拉伸或纵向压缩。
- **方案组与多图层支持**：  
  可同时开启多个准星图层（如十字线 + 中心点 + 环形 + 图片），支持将常用配置保存为不同的方案组快速切换。
- **开镜 / 开火自动隐藏**：  
  可针对指定图层设置按住鼠标左键或右键时自动隐蔽准星。
- **UI 全面自定义**：  
  内置系统原生调色板（支持所有颜色微调），并支持导入本地壁纸作为软件面板背景。

## 开发者编译

本项目不需要安装庞大的 Visual Studio，直接利用 Windows 自带的 .NET Framework 编译器即可：

1. 克隆或下载本仓库代码。
2. 双击运行根目录下的 `build.bat`。
3. 脚本会自动调用 `csc.exe` 完成编译，输出文件位于 `bin\ScreenCrosshair.exe`。
