## 二、 单一平面十字几何架构 (彻底根除上下堆叠与接缝)

### 为什么之前看起来像“上下堆叠”？
传统绘制方式通常是先在屏幕上画一条横线（带黑色外框），再在上面画一条竖线（带黑色外框）。
这会导致后画的竖线黑色外描边直接“切过”横线的彩色中心，使准星看起来像两根木棍一上一下钉在一起，严重影响瞄准专注度。

### ScreenCrosshair 单一平面解决方案：
1. **布尔并集统一拓扑**：
   - 引擎将十字准星的所有横向矩形与纵向矩形在内存中进行几何布尔求并（`CombinedGeometry Union`）。
2. **单一面片着色**：
   - 所有的填充颜色（Fill）在同一个 12 边形几何面片上一次性平整渲染，横线与竖线融为一体，毫无高低层级之分。
3. **外缘单一轮廓外描边**：
   - 黑色描边仅沿最终外边框绘制，并通过布尔剪裁（Clip）杜绝描边向内渗入。
   - 交叉十字中心没有任何纵横黑线杂质，呈现纯粹电竞级别的单一平面！

## 三、 自定义图片准星与纵横比锁定/拉伸压缩

1. **导入图片准星**：
   - 在【线条模式】选择 **`【自定义图片准星 (Custom PNG Image)】`**。
   - 点击 **`[ 📂 浏览选择准星图片 ]`** 选取电脑上的任意图片。
2. **纵横比锁定 (Lock Aspect Ratio)**：
   - **勾选 `[ 🔒 锁定图片宽高比 ]`**：调节宽度或高度滑块时，另一项自动按图片原本的长宽比等比例同步计算，准星永不形变。
   - **取消勾选**：解除比例锁定！此时宽度与高度滑块完全独立，准星将严格依照你设置的像素数值进行**横向拉伸、纵向压缩或压扁**，轻松调出各类椭圆环、扁平箭头或自创拉伸准星！

## 四、 物理屏幕直接鼠标拖拽定位 (Screen Drag Calibration)

1. **进入全屏校准**：
   - 在设计面板中间点击 **`[ 🎯 在真实物理屏幕上直接鼠标拖拽准星 (按ESC退出) ]`**。
2. **全屏任意拖拽**：
   - 准星中心亮起青色瞄准光圈，屏幕顶端浮现控制条。
   - **在屏幕任意区域按住鼠标左键拖动**，准星即刻跟随鼠标滑向目标靶心。
3. **退出锁定**：
   - 敲击键盘 **`ESC`**（或点击顶部 `[ 🔒 完成并锁定 ]` 按钮），光标瞬间穿透，锁定坐标恢复防封安全模式。

- 打开顶部导航 **【主题·按键·个性化】**。

- 主面板卡片即刻化为磨砂半透明玻璃质感，壁纸清晰透显，并可拖动滑块调整不透明度。

## 八、 方案组与图层双向流转系统

- **多层叠加**：横线 + 竖线 + 像素方块红点 + 扩散圆环 + 外部战术图片均可同屏叠加。
- **方案组流转**：支持 `[→ 存入组]`、`[+ 载入列表]`、`[⚡ 应用此组全部准星]`，随时一键切换整套配置。

## 九、 物理像素方块点 (绝对居中防偏心)

- **1px 方块点**：精准落在中心单颗硬件像素上，绝不跨像素模糊。
- **2px 方块点**：中心 2×2 对称四象限，绝对物理居中不偏心。
- **10x 微观放大镜**：在设计器右侧随时切换 1x ~ 16x 放大倍率并开启像素参考网格。
